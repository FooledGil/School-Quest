# 📖 SchoolQuest Documentation & Guide

Welcome to the **SchoolQuest** documentation hub. Comprehensive project documentation is integrated within the main [README.md](README.md) and the system restoration guide in [guide.md](guide.md).

## 📑 Quick Documentation Navigation

Here is a quick navigation guide to specific modules and topics in [README.md](README.md):

1. 🎯 [**Background & Philosophy (Why)**](README.md#-about-schoolquest)
   - Real-world challenges in vocational high schools (monotonous assignments, neglected cleaning duties, low student engagement).
   - Why gamification? (Educational psychology, instant feedback loops, achievement recognition).
   - Character building and discipline impact.

2. ⚔️ [**System Overview & Features (What)**](README.md#-key-features)
   - The Adventurers (Students) vs The Guild Masters (Teachers & Admins) concept.
   - Comprehensive student features (Interactive Dashboard, Auto Daily Quests, Transparent Proof Submission, 3D Podium Leaderboard, The Realm Forum, PixelBot Avatar).
   - Comprehensive teacher & admin features (Admin Dashboard, Quest Validation Center, Quest Builder CRUD, 220+ Student Directory, Moderation & Disciplinary Sanctions).
   - Gamification Eng`ine: Quadratic EXP curve formula, 14 Fantasy Ranks (*Novice* to *Immortal*), Daily Streaks, and Achievements.
   - Modern Monolith Architecture (Laravel 12, React 19, Inertia.js 3.x, Tailwind CSS v4, GSAP).
   - Relational Database schema with 14 Eloquent Models.

3. 🚀 [**Workflow & Operations (How)**](README.md#-quick-start-guide)
   - Interaction workflows for Students (task submission & photo evidence) and Teachers (validation, approvals, and rejections with feedback).
   - Quick Start Guide for Linux (automated script for Arch Linux `setup_arch.sh` and manual installation for Ubuntu/Debian/Windows WSL).
   - Ready-to-use demo credentials (Admin, Teacher, MPLB & RPL Students via Email, NISN, or Name).
   - Automated testing suite with PHPUnit 11 (`php artisan test`).
   - Troubleshooting and system maintenance.
